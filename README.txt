PLANT CARE REMINDER - COLLEGE MINI PROJECT

TECHNOLOGIES
- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

HOW TO RUN
1. Extract the plant-care-reminder folder.
2. Open the folder in Visual Studio Code.
3. Install the VS Code Live Server extension if it is not already installed.
4. Right-click index.html and choose Open with Live Server.
5. Register a demo account, log in, and start adding plants and reminders.

MAIN FEATURES
- User registration and login (demo authentication stored in LocalStorage)
- User-specific plant collections
- Built-in library of 18 plants, each with a real plant photograph
- Add library plants or create a custom plant
- Edit, search, view and delete plants
- Optional image upload for custom plants
- Watering, fertilizer and sunlight reminders
- Upcoming, completed and overdue reminder filters
- Recurring watering and fertilizer reminders
- Browser notifications while the website is open and permission is granted
- Plant care tips
- Responsive green-themed layout

BUILT-IN PLANT LIBRARY
Money Plant, Snake Plant, Aloe Vera, Peace Lily, Spider Plant, Tulsi, Jade Plant, Areca Palm,
Rose, Hibiscus, ZZ Plant, Mint, Monstera, Rubber Plant, Lucky Bamboo, English Ivy, Orchid,
and Curry Leaf Plant.

PHOTO NOTES
All 18 built-in plant photos are real photographs loaded from Unsplash or Wikimedia Commons. An
internet connection is required to display them. Each library card includes a Photo source link.
If a remote photo cannot load, the card shows a clear Photo unavailable message instead of pretending
an emoji or illustration is a real photograph. Existing built-in plants from an older project version
are automatically upgraded to the new photos when the My Plants page is opened. User-uploaded photos
are preserved.

IMPORTANT NOTES
- This is a frontend-only educational demonstration project, not a production account system.
- LocalStorage is specific to the browser and device. Clearing browser data may remove saved data.
- Passwords are stored in LocalStorage for demonstration only. Do not use real or reused passwords.
- Browser notifications require permission and generally work only while this website is open.
  They are not guaranteed when the browser is closed.
- Care schedules are starter guidance only. Check the actual soil, pot, climate and plant condition.
- Uploaded images are resized to reduce LocalStorage usage. If storage becomes full, use a smaller image.

SUGGESTED DEMONSTRATION / ACCEPTANCE TEST
1. Register a new demo account and log in.
2. Search the library for Monstera and add it; check that it appears in My Plants with its photo.
3. Add a custom plant, edit its name, then open its details.
4. Create one watering, one fertilizer and one sunlight reminder.
5. Edit a reminder, mark a recurring reminder complete, and confirm its next date is created.
6. Try Upcoming, Completed and Overdue filters, plus the type and plant search fields.
7. Refresh the page and confirm plants/reminders remain saved.
8. Enable browser notifications after granting permission (test while the website remains open).
9. Delete a plant with reminders and confirm whether its related reminders should also be deleted.
10. Log out, then log in again and confirm the saved collection remains.
